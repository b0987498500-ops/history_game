# 高黏著度歷史情境模擬 RPG 遊戲（教育＋商業手遊機制）

## 📖 專案概述
本專案為融合「第一人稱歷史情境模擬」、「數值養成」與「分支抉擇」的 Web RPG 遊戲。
以 19 世紀中後期清末臺灣大稻埕開港通商為核心舞台，採用商業手遊的爽感反饋機制（交易暴擊、金幣噴發、階級躍遷、收集圖鑑、結算評價戰報），兼具教育意義與高黏著度娛樂性。

---

## 🏛️ 系統架構設計

### 1. 核心迴圈 (Core Gameplay Loop)
```
[選擇身份開局]
       │
       ▼
[日常小遊戲] ──獲取──> [情報道具/時代秘笈]
       │                        │
       ▼                        ▼
[主線歷史節點] <──解鎖加權── [💡 推薦選項高亮]
       │
   [玩家抉擇]
  ┌────┴────────────────┐
  ▼                     ▼
[史實路線]            [If 架空路線]
(順應時代規律)       (蝴蝶效應演繹)
  │                     │
  └────┬────────────────┘
       ▼
[交易結算與暴擊判定] ──> [視覺外觀階層晉升]
       │
       ▼
[通關戰報結算 (S/A/B) 與歷史圖鑑收集]
```

### 2. 模組職責
- **Identity & Economy Loop (, )**：管理身份數值、銀兩資產、聲望與時代紅利交易暴擊（200% 利潤）。
- **Branching & State Machine ()**：節點導向劇情推進，包含史實線與架空 If 線成因剖析。
- **Clue & Guidance System ()**：碼頭貨物小遊戲獲取「大稻埕行商秘笈」，決策介面動態高亮優勢選項。
- **Visual Progression (, )**：粗布麻衣手推車 $	o$ 綾羅綢緞大掌櫃 $	o$ 三進大宅富商巨賈。
- **Synthesized Audio & Canvas VFX ()**：純程式碼 Web Audio 合成音效（金幣、暴擊、船鳴、通關樂）與金幣噴發粒子系統。
